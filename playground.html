Publish it as your own website

This is CA1 and Unit 6 in miniature. Your project has to live in a GitHub repo and be deployed online — so practise it here first with a page that does not matter.
  1. Press Download index.html above.
  2. Create a free account at github.com if you have none.
  3. Make a new public repository. Any name will do.
  4. On the empty repo page click uploading an existing file and drag your index.html in. Commit it.
  5. Go to Settings → Pages, set Source to Deploy from a branch, branch main, folder / (root), and Save.
  6. Wait a minute, then open https://YOURNAME.github.io/YOURREPO/

Two traps that catch everyone. The file must be named exactly index.html, and the web server is case-sensitive even though Windows is not — so Photo.JPG and photo.jpg are different files once deployed. That single difference breaks more CA1 submissions than anything else.
