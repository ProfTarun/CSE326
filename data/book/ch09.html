SVG Graphics

SVG lets you draw with code: circles, rectangles, lines, curves and text that stay perfectly sharp at any size. This chapter explains why vector graphics differ from photographs, how the SVG coordinate system works, every basic shape and its attributes, how fill and stroke paint them, and enough of the path language to read and write simple drawings. Every diagram in this book is an SVG.

About 22 minutes · Course outcome CO1

By the end of this chapter you can

  • Explain raster versus vector and when to choose SVG.
  • Read width, height, viewBox and preserveAspectRatio and predict how a drawing scales.
  • Draw with rect, circle, ellipse, line, polyline, polygon, path and text.
  • Control appearance with fill, stroke, stroke-width, stroke-dasharray and stroke-linecap.
  • Make an inline SVG accessible.

9.1 Raster versus vector

A JPG or PNG is a raster image: a grid of coloured pixels. Enlarge it and the browser has to invent pixels that were never there, so it goes blurry or blocky. An SVG (Scalable Vector Graphics) file stores drawing instructions instead: "a circle of radius 40 centred at (70, 70), filled orange". The browser re-draws those instructions at whatever size is needed, so the result is sharp at any zoom level or screen size. That is why SVG is the right format for logos, icons, diagrams and illustrations, and why a company logo should be SVG rather than JPG. Photographs, with millions of subtly different pixels, stay raster.

SVG can be used two ways: as a separate file referenced like any image (<img src="logo.svg" alt="LPU">), or written inline directly inside the HTML as an <svg> element. Inline SVG can be styled with CSS and changed with JavaScript, which is why this book, and most modern sites, use it for icons and diagrams. It is often tiny for simple shapes, and it can be styled: change the stroke colour in DevTools and the drawing updates live.

9.2 The canvas: svg, width, height and viewBox

The <svg> element creates the drawing area. width and height set the rendered size on the page. viewBox sets the internal coordinate system, the grid the drawing instructions are measured on: viewBox="min-x min-y width height". So viewBox="0 0 100 100" says "my drawing is described on a 100 × 100 grid starting at the top-left"; the browser then maps that grid onto whatever rendered size you gave.

Three consequences that are examined:

  • Scaling. Given <svg viewBox="0 0 200 100" width="400">, the 200-unit-wide grid is drawn 400px wide, so each unit is 2px, and a <rect width="100"> inside it appears 200 pixels wide on screen.
  • Clipping. Anything outside the viewBox range is simply not drawn. If your viewBox is 0 0 100 100 and a shape uses coordinates near 500, it is clipped and appears to vanish; no error, no automatic scaling.
  • Aspect ratio. When the viewBox and the rendered box have different proportions, preserveAspectRatio controls how the viewBox is scaled and aligned inside the available viewport. The default, xMidYMid meet, keeps the proportions, fits the whole drawing inside and centres it; slice fills the box and crops; none stretches the drawing to fill exactly. It has nothing to do with paint order, colour depth or stroke thickness.
<svg viewBox="0 0 100 100" width="50" height="50"><circle cx="50" cy="50" r="40" fill="orange"/></svg>
<svg viewBox="0 0 100 100" width="100" height="100"><circle cx="50" cy="50" r="40" fill="orange"/></svg>
<svg viewBox="0 0 100 100" width="130" height="130"><circle cx="50" cy="50" r="40" fill="orange"/></svg>

Notice that inside SVG, void-style elements are closed with a slash (<circle ... />) because SVG follows XML rules; inline in HTML5 the browser accepts either form, but the slash is the convention.

9.3 The basic shapes

SVG has six basic shape elements plus path. There is no <triangle>, <oval> or <arc> element: triangles are polygons, ovals are ellipses, arcs are paths.

ElementPositioning attributesExample
<rect>x, y = top-left corner; width, height; rx (and ry) round the corners<rect x="20" y="25" width="120" height="70" rx="12"/>
<circle>cx, cy = centre; r = radius<circle cx="70" cy="70" r="40"/>
<ellipse>cx, cy = centre; rx, ry = horizontal and vertical radii. If rx = ry it is a perfect circle<ellipse cx="50" cy="50" rx="40" ry="20"/>
<line>x1, y1 = start; x2, y2 = end. Must have a stroke to be visible<line x1="20" y1="20" x2="240" y2="110" stroke="black"/>
<polyline>points = a list of x,y pairs; the shape stays open<polyline points="0,80 40,20 80,80"/>
<polygon>points as above; the shape is closed automatically back to the first point<polygon points="50,0 100,100 0,100"/> is a triangle
<text>x, y = the start of the baseline<text x="40" y="90">CSE326</text>

Note the different vocabularies: a rect is positioned from its top-left corner with x and y, while a circle or ellipse is positioned from its centre with cx and cy. A line has no area, so it has no fill: give it a stroke or it renders as nothing. And polyline versus polygon: the only difference is that polygon closes back to the start point, polyline does not.

<svg viewBox="0 0 520 180" width="520" height="180" style="border:1px solid #ccc">
  <rect x="20" y="30" width="100" height="60" rx="12" fill="#FFF1E0" stroke="#E07B1E" stroke-width="2"/>
  <circle cx="180" cy="60" r="35" fill="#E9F7E7" stroke="#138808" stroke-width="2"/>
  <ellipse cx="290" cy="60" rx="50" ry="25" fill="#EEF2FF" stroke="#4F46E5" stroke-width="2"/>
  <line x1="360" y1="90" x2="440" y2="30" stroke="black" stroke-width="3"/>
  <polyline points="460,90 480,40 500,80 515,30" fill="none" stroke="red" stroke-width="3"/>
  <polygon points="70,170 120,110 20,110" fill="gold" stroke="black"/>
  <path d="M180 170 Q230 100 280 170" fill="none" stroke="green" stroke-width="3"/>
  <text x="330" y="160" font-size="22" fill="#0B2545">Campus Map</text>
</svg>

9.4 Painting: fill and stroke

Two attributes control almost all appearance. fill is the colour inside a shape; stroke is the colour of its outline. Both accept any CSS colour: names, hex codes, rgb(). fill="none" makes a shape hollow, which is how open shapes like polylines and curves are normally drawn.

AttributeControlsValues
fillInterior colourorange, #E07B1E, none
strokeOutline colourany colour; default is none (no outline)
stroke-widthThickness of the outlinea number, e.g. 3
stroke-dasharrayDashed outline: dash length, gap length"8,6" = 8-unit dashes with 6-unit gaps
stroke-linecapThe shape of a line's endsbutt (flat, exactly at the endpoint; the default), round, square (flat but extended by half the width)
opacity, fill-opacity, stroke-opacityTransparency0 to 1
 
<svg viewBox="0 0 400 100" width="400" height="100">
  <rect x="10" y="10" width="110" height="80" fill="#FFF1E0" stroke="#E07B1E" stroke-width="4"/>
  <circle cx="200" cy="50" r="38" fill="none" stroke="#138808" stroke-width="6" stroke-dasharray="8,6"/>
  <line x1="270" y1="20" x2="390" y2="80" stroke="#0B2545" stroke-width="10" stroke-linecap="round"/>
</svg>

9.5 The path element

<path> draws anything: its d attribute is a tiny language of commands, each a letter followed by numbers. You do not need to master curves for this course, but you must be able to read the straight-line commands and know what Z and lowercase letters mean.

CommandMeaning
M x yMove the pen to (x, y) without drawing
L x yDraw a straight line to (x, y)
H xDraw a horizontal line to the given x coordinate
V yDraw a vertical line to the given y coordinate
Q cx cy x yQuadratic curve to (x, y) bending toward the control point (cx, cy)
C ..., A ...Cubic curves and elliptical arcs (advanced)
ZClose the path: draw a straight line back to the start point

Uppercase commands use absolute coordinates; lowercase commands are relative to the current pen position. L 100 50 goes to the point (100, 50); l 100 50 goes 100 to the right and 50 down from wherever the pen is. Lowercase is not invalid and not identical to uppercase; it is relative.

<svg viewBox="0 0 360 120" width="360" height="120" style="border:1px solid #ccc">
  <!-- M: move to (10,100); L: line to (60,20); H: horizontal to x=110; V: vertical to y=100; Z: close -->
  <path d="M10 100 L60 20 H110 V100 Z" fill="#FFF1E0" stroke="#E07B1E" stroke-width="3"/>
  <!-- the same shape with RELATIVE (lowercase) commands, moved to the right -->
  <path d="M140 100 l50 -80 h50 v80 z" fill="#E9F7E7" stroke="#138808" stroke-width="3"/>
  <!-- Q: a curve from (250,100) to (350,100) pulled toward (300,10) -->
  <path d="M250 100 Q300 10 350 100" fill="none" stroke="#0B2545" stroke-width="3"/>
</svg>

9.6 Text, groups and accessibility

<text x y> places a text label inside the drawing; font-size, fill and text-anchor="middle" style and centre it. <g> groups elements so they can be moved or styled together (<g transform="translate(50,20)">).

An inline SVG has no alt attribute; alt exists only on img, area and input. To describe an inline SVG for screen readers, give the <svg> element role="img" and an aria-label (or a <title> element as its first child). A decorative SVG gets aria-hidden="true".

<svg viewBox="0 0 200 100" width="200" height="100" role="img" aria-label="CSE326 badge: a green circle with the course code">
  <circle cx="50" cy="50" r="40" fill="#138808"/>
  <text x="50" y="57" font-size="18" fill="white" text-anchor="middle">326</text>
  <g transform="translate(110,0)">
    <rect x="0" y="30" width="80" height="40" rx="8" fill="#FF9933"/>
    <text x="40" y="56" font-size="16" fill="white" text-anchor="middle">CSE</text>
  </g>
</svg>

9.7 Worked examples

Draw a circle of radius 40 centred at (70, 70). Centre means cx/cy, radius means r: <circle cx="70" cy="70" r="40"/>. Not x/y (those belong to rect), not <ellipse ... r> (ellipse uses rx/ry), not <rect cx cy r>.

What does <ellipse cx="50" cy="50" rx="40" ry="40"/> render? Equal radii: a perfect circle.

Draw a triangle. A closed three-point shape is a polygon: <polygon points="50,0 100,100 0,100"/>. A polyline with the same points would leave the last side open; rect and path do not take a points attribute.

Why does my line not show? A <line> has no area, so it has no fill; without a stroke it is invisible. Add stroke="black".

Why did my shape vanish? Its coordinates (near 500) are outside the viewBox="0 0 100 100"; it is clipped. Enlarge the viewBox or move the shape.

How wide is it on screen? <svg viewBox="0 0 200 100" width="400"> draws 200 units in 400px: 2px per unit. A rect width="100" shows as 200px.

Exam-style checks

What does SVG stand for, and why does an SVG stay sharp when enlarged?L1

Answer: Scalable Vector Graphics. It stores drawing instructions, not a pixel grid, so the browser re-draws the shapes at whatever size is needed.

Why is SVG preferred over JPG for a company logo?L2
  • A. SVG files are always smaller than JPG files
  • B. SVG supports a wider range of colours
  • C. SVG stays sharp at any zoom level or screen size
  • D. SVG cannot be copied by users

Answer: C. Logos are shapes; vectors scale without blur.

What does viewBox="0 0 100 100" define on an <svg> element?L3
  • A. The colour palette used by the drawing
  • B. The internal coordinate space the drawing is mapped into
  • C. The border thickness of the SVG canvas
  • D. The animation duration in seconds

Answer: B. width and height set the rendered size; viewBox sets the coordinate grid.

In SVG, which way does the y axis grow?L2

Answer: downward from the top-left. Screen coordinates, not graph paper.

Given <svg viewBox="0 0 200 100" width="400">, a <rect width="100"> inside it appears how many pixels wide on screen?L3
  • A. 400
  • B. 100
  • C. 200
  • D. 50

Answer: C. 200 units are drawn in 400px, so 1 unit = 2px and 100 units = 200px.

Your shape uses coordinates near 500 but viewBox is "0 0 100 100". What happens?L3

Answer: it is clipped and appears to vanish. Anything outside the viewBox range is not drawn; nothing scales automatically and no error is shown.

What does the preserveAspectRatio attribute on an <svg> control?L3
  • A. The order in which shapes are painted
  • B. The colour depth of the rendered graphic
  • C. The thickness of every stroke in the drawing
  • D. How the viewBox is scaled and aligned inside the available viewport

Answer: D. The default xMidYMid meet fits and centres; none stretches; slice fills and crops.

Which SVG element draws a circle of radius 40 centred at (70, 70)?L2
  • A. <circle x="70" y="70" r="40" />
  • B. <circle cx="70" cy="70" r="40" />
  • C. <ellipse cx="70" cy="70" r="40" />
  • D. <rect cx="70" cy="70" r="40" />

Answer: B. Circles use cx, cy and r.

Which attributes position an SVG <rect> from its top-left corner?L2
  • A. x and y
  • B. cx and cy
  • C. rx and ry
  • D. x1 and y1

Answer: A. cx/cy are centres (circle, ellipse); rx/ry are corner radii on rect; x1/y1 belong to line.

Which SVG attribute rounds the corners of a <rect> element?L2
  • A. radius
  • B. r
  • C. rx
  • D. corner

Answer: C. rx (with optional ry). r is a circle's radius.

Which attribute pair sets the two endpoints of an SVG <line>, and why must a line always be given a stroke?L2

Answer: x1, y1 and x2, y2. A line has no fill, so stroke is the only way it becomes visible.

Which SVG element draws an ellipse, and what does <ellipse cx="50" cy="50" rx="40" ry="40" /> render?L3

Answer: <ellipse> (there is no oval or arc element); with rx equal to ry it renders a perfect circle.

How does <polyline> differ from <polygon>?L3
  • A. <polyline> supports curves while <polygon> does not
  • B. <polyline> does not automatically close back to the start point; <polygon> does
  • C. <polygon> is limited to exactly three points
  • D. There is no functional difference between them

Answer: B. Both take a points list; only polygon closes the shape.

Which SVG element and points list draws a triangle?L3

Answer: <polygon points="50,0 100,100 0,100" />. polyline would leave it open; rect and path have no points attribute; there is no <triangle> element.

Which of the following is NOT a valid SVG basic shape element: polygon, triangle, ellipse, polyline?L3

Answer: triangle. Triangles are drawn with polygon (or path).

In SVG, fill and stroke respectively control:L2
  • A. The inside colour and the outline colour of a shape
  • B. The outline colour and the inside colour of a shape
  • C. The shape's width and its height
  • D. The shape's opacity and its rotation

Answer: A.

Which SVG attribute sets the thickness of a shape's outline?L1
  • A. line-width
  • B. fill-width
  • C. border-width
  • D. stroke-width

Answer: D.

What does stroke-dasharray="8,6" produce on an SVG line?L3

Answer: dashes 8 units long separated by 6-unit gaps.

Which stroke-linecap value ends an SVG line flat and exactly at its endpoint?L3
  • A. flat
  • B. round
  • C. square
  • D. butt

Answer: D. butt is the default; square is also flat but extends beyond the endpoint; round is rounded.

Which command in an SVG <path> d attribute draws a horizontal line to a given x coordinate, and what does Z do?L3

Answer: H draws horizontally to x (V is vertical, L is a line to x,y, M moves). Z draws a straight line back to the start point, closing the path.

Lowercase commands in a <path> d attribute (for example l instead of L) are interpreted as:L3

Answer: relative to the current pen position. They are valid and differ from uppercase, which is absolute.

Which SVG element places a text label inside a drawing?L1
  • A. <tspan>
  • B. <label>
  • C. <text>
  • D. <caption>

Answer: C. (tspan is a span inside text; label and caption are HTML elements.)

How do you give an inline <svg> an accessible description?L2

Answer: role="img" with aria-label (or a title child). alt exists only on img, area and input.

Quick revision

Key takeaways

  1. SVG = Scalable Vector Graphics: instructions, not pixels; sharp at any size; ideal for logos, icons and diagrams.
  2. width/height = rendered size; viewBox = coordinate grid (origin top-left, y down). Units scale (viewBox 200 wide at width 400: 2px per unit); shapes outside the viewBox are clipped; preserveAspectRatio (default xMidYMid meet) controls fit and alignment.
  3. rect x y width height rx; circle cx cy r; ellipse cx cy rx ry (rx=ry is a circle); line x1 y1 x2 y2 (needs stroke); polyline points (open); polygon points (closed; triangle); text x y.
  4. fill = inside; stroke = outline; stroke-width, stroke-dasharray "8,6", stroke-linecap butt/round/square.
  5. path d: M move, L line, H horizontal, V vertical, Q curve, Z close; lowercase = relative.
  6. Accessibility: role="img" + aria-label on inline SVG.
