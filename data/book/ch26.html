Unit 3 · Chapter 26 · Typography

Typography

Typography is the choice and arrangement of the letters themselves: which typeface, how big, how heavy, how far apart the lines sit. Get it right and a page feels calm and professional before anyone reads a word. This chapter covers the six properties that do ninety per cent of the work, and why font-family is a list rather than a single name.

About 21 minutes · Course outcome CO3

Before you start — one-line reminders

  • rem is measured against the root font size, 16px by default (Chapter 25).
  • Font properties are inherited: set them on body and the page follows (Chapter 23).

By the end of this chapter you can

  • Write a font-family stack and explain why it has several names in it.
  • Name the five generic families and when each is used.
  • Set size, weight and style, and know that 400 is normal and 700 is bold.
  • Set line-height correctly — and say why it has no unit.
  • Load a web font from Google Fonts and keep a fallback.

26.1 font-family: a list, not a name

font-family specifies the typeface used to display text. The surprise for beginners is that you give it a list:

body {
  font-family: "Segoe UI", Roboto, Helvetica, Arial, sans-serif;
}

Why a list? Because the font has to exist on the reader's computer, not on yours. Your machine may have a font that a phone in another country has never heard of. So you give the browser a preference order:

  1. Try Segoe UI. Present on Windows — use it.
  2. Not there? Try Roboto. Present on Android.
  3. Still nothing? Helvetica, then Arial.
  4. If none of them exist, fall back to sans-serif — whatever plain font this device has.

This list is called a font stack. Two rules for writing one:

  • Quote any name containing a space: "Segoe UI", "Times New Roman". Single-word names need no quotes.
  • Always end with a generic family. It is the last line of defence and it never fails.
Picture this. A font stack is like telling a friend which shop to buy from: "the bakery on Mall Road, or if it is shut the one near the station, or failing that any bakery." You do not know what is open in their town, so you give an order of preference and a safe fallback.

The five generic families

A practical shortcut: font-family: system-ui, sans-serif; asks for the device's own interface font — Segoe UI on Windows, San Francisco on a Mac or iPhone, Roboto on Android. The page then looks native everywhere, loads nothing extra, and is one line long.

<style>
  p { font-size: 18px; margin: 6px 0; }
  .s { font-family: Georgia, "Times New Roman", serif; }
  .n { font-family: system-ui, Arial, sans-serif; }
  .m { font-family: "Cascadia Code", Consolas, monospace; }
  .x { font-family: "A Font Nobody Has", cursive; }
</style>
<p class="s">Serif: the quick brown fox jumps over the lazy dog.</p>
<p class="n">Sans-serif: the quick brown fox jumps over the lazy dog.</p>
<p class="m">Monospace: the quick brown fox jumps over the lazy dog.</p>
<p class="x">Missing font: the browser fell back to cursive.</p>

26.2 Size, weight and style

font-size

Controls how big the letters are. Use rem so the reader's own setting is respected (Chapter 25).

body { font-size: 1rem; }      /* 16px */
h1   { font-size: 2rem; }      /* 32px */
small{ font-size: 0.875rem; }  /* 14px */

font-weight

Controls the thickness — how bold the letters are. You can write keywords or numbers:

ValueMeans
100 – 300Light
400 or normalNormal body text — the default
500, 600Medium, semi-bold
700 or boldBold — what <b> and <strong> use
800, 900Extra bold, black

A font only shows the weights it actually contains. Ask for 900 from a font that has only normal and bold and the browser gives you the closest it has, or fakes it.

font-style

Controls whether text is upright or slanted: normal, italic, or oblique. italic uses the font's own designed italic letters; oblique simply slants the upright ones. Prefer italic.

Style with CSS, mean it with HTML. font-weight: 700 only makes letters thick. If the text is genuinely important, mark it as <strong> in the HTML so screen readers know (Chapter 6). CSS changes appearance; HTML carries meaning.

26.3 line-height: the most under-used property in CSS

line-height controls the vertical space between lines of text. It is the single biggest lever you have on readability, and beginners almost never touch it.

Write it as a plain number with no unit:

body { line-height: 1.7; }   /* 1.7 times the font size */

A unitless value means "this many times the element's own font size", and it is recalculated for every element that inherits it. Write line-height: 27px instead and every heading inherits 27px too — which is far too tight for a 32px heading, and the lines overlap. This is a real bug that a unitless value prevents.

ValueLooksUse for
1Cramped, lines nearly touchingNothing, usually
1.2TightLarge headings
1.5 – 1.8ComfortableBody text. WCAG suggests at least 1.5
2.5Loose — lines feel unrelatedNothing, usually

Change the sliders below and read each version. The difference between 1.1 and 1.7 is not decoration; it is whether people finish your paragraph.

Typography, live — find the settings you would actually read
Typography is the craft of arranging letters so that they are easy and pleasant to read. Change the sliders and notice how much difference the line height alone makes to whether you want to keep reading this sentence to its end.

  






  
26.4 Spacing between letters and words

  
    
    
  • letter-spacing adds space between every letter. A small positive value (0.05em) suits small capitals and short headings. Never use it on body text — it slows reading down.
    • 
    
  • word-spacing adds space between words. Rarely needed.
    • 
  

  
<style>
  .eyebrow {
    font-size: 0.75rem;
    font-weight: 800;
    letter-spacing: 0.14em;
    text-transform: uppercase;
    color: #B45309;
  }
</style>
<p class="eyebrow">Unit 3 · Chapter 26</p>
<h2 style="margin-top:4px">Typography</h2>

  
That little uppercase label above a heading is one of the most reusable patterns in web design, and it is four declarations long.






  
26.5 The font shorthand

  
You can write several font properties in one declaration. The order is fixed, and size and family are compulsory:

  
/* style  weight  size / line-height  family */
font: italic 700 1.25rem/1.6 Georgia, serif;

/* the long way, which is what most people write */
font-style: italic;
font-weight: 700;
font-size: 1.25rem;
line-height: 1.6;
font-family: Georgia, serif;

  
The shorthand is compact but unforgiving: anything you leave out is silently reset to its default. The long form is clearer, and clearer wins.






  
26.6 Web fonts

  
If you want a typeface that is not on the reader's device, the browser must download it. The easiest route is a free service such as Google Fonts, which gives you a <link> to paste into your <head>:

  
<!-- in the head of the HTML -->
<link href="https://fonts.googleapis.com/css2?family=Poppins:wght@400;700&display=swap"
      rel="stylesheet">

/* then in the CSS */
body { font-family: "Poppins", system-ui, sans-serif; }

  
Notice that the fallback stack is still there. If the download is slow or blocked, the page must stay readable.

  
Three rules of thumb:

  
    
    
  • Two families at most — one for headings, one for text. Three looks like a ransom note.
    • 
    
  • Only the weights you use. Each weight is a separate file to download.
    • 
    
  • Keep display=swap, so text appears in the fallback font immediately instead of the reader staring at a blank space.
    • 
  

  
The underlying mechanism is the @font-face rule, which names a font and gives the browser a file to fetch. Services generate it for you; you rarely write it by hand.






  
26.7 Making text comfortable to read

  
Four settings do most of the work. None of them is a matter of taste:

  

    
SettingAim forWhy

    
      
Body size1rem (16px) or a little moreSmaller is a struggle on a phone

      
Line height1.5 to 1.8The eye needs a clear path back to the next line

      
Line lengthmax-width: 65chVery long lines make readers lose their place

      
ContrastAt least 4.5:1WCAG Level AA (Chapter 20)

    
  

  
<style>
  body {
    font-family: system-ui, "Segoe UI", Roboto, Arial, sans-serif;
    font-size: 1rem;
    line-height: 1.7;
    color: #3C4A60;
    max-width: 65ch;          /* about 65 characters per line */
    margin: 0 auto;
    padding: 1.5rem;
    background: #FBFCFE;
  }
  h1 {
    font-family: Georgia, "Times New Roman", serif;
    font-size: 2rem;
    line-height: 1.2;
    color: #0B2545;
    margin-bottom: 0.25rem;
  }
  .eyebrow {
    font-size: 0.75rem; font-weight: 800; letter-spacing: 0.14em;
    text-transform: uppercase; color: #B45309; margin: 0;
  }
  .lead { font-size: 1.15rem; }
</style>
<p class="eyebrow">Student profile</p>
<h1>Asha Kumar</h1>
<p class="lead">B.Tech Computer Science, first year.</p>
<p>A serif heading over a sans-serif body is a classic pairing: the two are
different enough to separate clearly, and neither is shouting.</p>






  
Exam-style checks

  
Which property specifies the typeface used to display text?L1

    
  • A. font-style
  • B. font-family
  • C. typeface
  • D. text-font

    
Answer: B. font-style chooses italic or normal; typeface and text-font do not exist.

  
Why does font-family usually list several names?L3

    
Because the font has to exist on the reader's device. The browser tries each name in order and uses the first one it has, ending with a generic family such as sans-serif that never fails. The list is called a font stack.

  
Which of these is NOT a generic font family?L2

    
  • A. serif
  • B. sans-serif
  • C. monospace
  • D. bold

    
Answer: D. bold is a font-weight value. The five generic families are serif, sans-serif, monospace, cursive and fantasy.

  
Which property controls the thickness or boldness of text, and what numeric value is normal?L1

    
font-weight, where 400 is normal and 700 is bold. The scale runs from 100 (light) to 900 (black).

  
Which property controls whether text appears normal, italic or oblique?L1

    
font-style. italic uses the font's designed italic letters; oblique just slants the upright ones.

  
Which property controls the vertical space between lines of text?L1

    
line-height. Around 1.5 to 1.8 is comfortable for body text; 1 is cramped.

  
Why is line-height: 1.6 better than line-height: 26px?L3

    
A unitless value is recalculated for each element from its own font size. A fixed 26px is inherited as 26px by a 32px heading as well, so the heading's lines end up too close together, or even overlapping.

  
A font name contains a space, such as Times New Roman. How is it written in font-family?L2

    
In quotes: font-family: "Times New Roman", Georgia, serif;. Single-word names need no quotes.

  
You load a Google Font. Why keep system-ui, sans-serif after it in the stack?L3

    
So the page stays readable if the download is slow, blocked or fails. The fallback is used until (or instead of) the web font arriving.

  
Which declaration keeps a line of text at a comfortable reading length?L2

    
max-width: 65ch; — the ch unit is the width of the digit "0" in the current font, so 65ch is roughly 65 characters. Long lines make readers lose their place on the way back.
