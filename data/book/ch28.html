The Box Model

Every single thing on a web page is a rectangle, even when it does not look like one. Once you can see those rectangles and their four layers, layout stops being guesswork. This is the most important chapter in Unit 3 — and it contains the one line of CSS that professionals put at the top of every stylesheet they write.

About 29 minutes · Course outcome CO3 · Everything after this depends on it

Before you start — one-line reminders

  • Block elements take a whole line; inline elements sit in the flow of text (Chapter 5).
  • px is fixed, % is a share of the parent, em follows the font size (Chapter 25).
  • Box properties such as padding and border are not inherited (Chapter 23).

By the end of this chapter you can

  • Name the four layers of a box in order and say which one takes the background colour.
  • Read padding: 5px 10px 15px 20px and say which side gets which value.
  • Work out how wide an element really is, and fix it with box-sizing: border-box.
  • Round corners, add a shadow, and centre a fixed-width box.
  • Explain why two stacked paragraphs have one gap between them, not two.

28.1 Everything is a box

A heading is a box. A paragraph is a box. A link inside that paragraph is a small box sitting in the line. An image is a box. The page itself is a box. The browser lays out a page by working out the size and position of thousands of rectangles.

Open any website, press F12 and hover over the elements: the browser draws each box for you in colours. Those colours are the four layers of the box model.

Content
The text, image or child elements. Its size is set by width and height, or by the content itself.
Padding — space inside the border
Breathing room between the content and the edge. Padding takes the element's background colour.
Border — the edge itself
A line drawn round the padding. It has a width, a style and a colour.
Margin — space outside the border
Distance from other elements. Margin is always transparent — you can never colour it.
Picture this. A framed photograph on a wall. The photo is the content. The white mount around it is the padding — inside the frame, and the same paper colour. The wooden frame is the border. The empty wall between this frame and the next one is the margin — you cannot paint it as part of the picture, because it belongs to the wall.

Padding pushes the edge away from the content. Margin pushes other elements away from the edge. If the background colour spreads into the space you added, it was padding.

<style>
  .wrap { background: #E3E9F0; }
  .pad  { background: #FFF1E0; border: 3px solid #E07B1E; padding: 26px; }
  .mar  { background: #E9F7E7; border: 3px solid #138808; margin: 26px; }
</style>
<div class="wrap">
  <div class="pad">26px of PADDING: the cream background fills it.</div>
  <div class="mar">26px of MARGIN: the grey page shows through instead.</div>
</div>

28.2 Borders

  
Any element can have a border. The border shorthand takes three things, in any order:

  
border: 2px solid #E07B1E;
/*      |   |     |
        |   |     colour
        |   style  <-- COMPULSORY
        width                        */

  
The style must be given. Write border: 2px #E07B1E and nothing appears at all, because the default style is none. That silent failure catches everyone once.

  

    
StyleLooks like

    
      
solidAn unbroken line — what you want almost always

      
dashed / dottedDashes / dots

      
doubleTwo parallel lines

      
noneNo border. The default.

    
  

  
You can also style one side at a time, which is how that fashionable coloured stripe down the left of a card is made:

  
<style>
  .quote {
    border-left: 5px solid #E07B1E;
    background: #FFF8F0;
    padding: 12px 16px;
  }
</style>
<div class="quote">A single coloured edge is often all a card needs.</div>

  
border-radius

  
border-radius rounds the corners. A small value (8px) softens a card; a very large one (999px) makes a pill; 50% on a square makes a circle.

  
<style>
  div { background: #138808; color: #fff; padding: 14px; margin-bottom: 10px;
        display: inline-block; font-weight: 700; }
  .r { border-radius: 10px; }
  .p { border-radius: 999px; }
  .c { border-radius: 50%; width: 76px; height: 76px; text-align: center; }
</style>
<div class="r">Rounded card</div>
<div class="p">Pill button</div>
<div class="c">Circle</div>

  
box-shadow

  
Like text-shadow (Chapter 27), but for the whole box: x-offset y-offset blur spread colour.

  
<style>
  div { background: #fff; padding: 16px; border-radius: 12px; margin: 14px 0; }
  .a { box-shadow: 0 2px 6px rgba(16,32,64,.12); }
  .b { box-shadow: 0 10px 28px rgba(16,32,64,.22); }
</style>
<div class="a">A small shadow: resting on the page.</div>
<div class="b">A bigger, softer shadow: floating above it.</div>

  
Shadows read as height. A small, soft, almost-transparent shadow looks professional; a hard black one looks like 2005.

  
Border or outline? outline draws a line too, but outside the border and without taking up any space, so adding one never shifts the layout. That is exactly why it is the browser's default focus indicator (Chapter 35). Use border for design, outline for focus.






  
28.3 Shorthand: one, two, three or four values

  
padding, margin, border-width and border-radius all accept up to four values, and the number you give changes the meaning. This is examined constantly.

  
  

    
WrittenTopRightBottomLeft

    
      
padding: 10px10101010

      
padding: 10px 20px10201020

      
padding: 10px 20px 30px10203020

      
padding: 5px 10px 15px 20px5101520

    
  

  
You can also name one side: padding-top, margin-left, border-bottom-width. Use the shorthand when you are setting several sides and a single property when you are setting one.

  
Quick check: in padding: 5px 10px 15px 20px, which side gets 15px? And in padding: 10px 20px, what does 20px apply to?

    
15px is the bottom — clockwise from the top gives top, right, bottom, left. And in the two-value form, 20px is left and right, because two values mean vertical then horizontal.






  
28.4 The width problem, and the one-line fix

  
Here is the trap that costs beginners hours. You give a box a width of 200px and some padding. How wide is it on screen?

  
.box {
  width: 200px;
  padding: 20px;
  border: 5px solid navy;
}

  
By default, width sets the width of the content only. Padding and border are then added outside that. So the real width is:

  
  
box-sizing: border-box changes the meaning of width so that it includes the padding and the border. Ask for 200px and you get 200px on screen, with the padding taken out of the inside.

  
<style>
  .ruler { width: 250px; border-top: 3px solid #C42B2B; margin-bottom: 4px; }
  .a, .b { width: 200px; padding: 20px; border: 5px solid #0B2545;
           background: #FFF1E0; margin-bottom: 14px; }
  .b { box-sizing: border-box; }
</style>
<div class="ruler"></div>
<div class="a">No box-sizing: I am really 250px wide.</div>
<div class="b">box-sizing: border-box: I am exactly 200px.</div>
<p style="font-size:14px;color:#6B7A90">The red line above is 250px, for comparison.</p>

  
This is why nearly every professional stylesheet opens with:

  
* {
  box-sizing: border-box;
}

  
One rule, applied to everything, and an entire category of sizing bug disappears. Put it at the top of every stylesheet you write from now on.






  
28.5 Margins: collapsing, and centring

  
Vertical margins collapse

  
Two paragraphs, each with margin: 20px 0. How much space is between them — 40px or 20px?

  
20px. When two vertical margins meet, they do not add up; the larger one wins and the smaller disappears inside it. This is called margin collapse, and it applies only to top and bottom margins, never to left and right.

  
It sounds like a bug and is actually a kindness: without it, the gap between two paragraphs would be double the gap you asked for. When you truly need the space to add up, use padding instead, or put the elements in a flex or grid container with a gap (Chapters 30 and 31), where margins do not collapse.

  
margin: 0 auto centres a box

  
To centre a block element horizontally you need two things: a width smaller than the parent, and margin-left and margin-right set to auto. auto means "share the leftover space", and with both sides asking, it is split evenly.

  
<style>
  .page {
    max-width: 320px;      /* a width, so there is space left over */
    margin: 0 auto;        /* 0 top and bottom, auto left and right */
    background: #FFF1E0;
    border: 2px solid #E07B1E;
    padding: 14px;
  }
</style>
<div class="page">Centred, whatever the window width. Resize the preview and watch.</div>

  
Why margin: 0 auto sometimes does nothing. Three usual reasons: (1) the element has no width, so it already fills the line and there is nothing left over to share; (2) it is an inline element such as a <span>, which ignores width — give it display: block first (Chapter 29); (3) you are trying to centre vertically, which auto margins do not do — use Flexbox for that (Chapter 30).

  
A negative margin is legal and pulls an element towards its neighbour. It is occasionally useful and frequently confusing; avoid it until you are comfortable.






  
28.6 Width, height and their sensible cousins

  

    
PropertyMeansTypical use

    
      
width, heightAn exact sizeAvatars, icons, fixed panels

      
max-width"Never wider than this, but shrink if you must"max-width: 65rem on a page wrapper — the single most useful responsive declaration

      
min-width"Never narrower than this"Stopping a button collapsing round short text

      
min-height"At least this tall, taller if the content needs it"Hero panels, cards of even height

      
height: auto"As tall as the content" — the defaultNearly always leave it alone

    
  

  
Prefer max-width to width for anything that must survive a phone. width: 800px forces a sideways scrollbar on a 375px screen; max-width: 800px simply becomes 375px wide when that is all the room there is.

  
Fixing a height is riskier still: if the text grows, or the reader enlarges their font, the content spills out of the box. Let height come from the content and use min-height when you need a floor.






  
28.7 Build it: a real card

  
Everything in this chapter, in the shape you will use a hundred times.

  
<style>
  * { box-sizing: border-box; }               /* the one-line fix, first */

  body {
    font-family: system-ui, sans-serif; color: #3C4A60; line-height: 1.6;
    background: #F1F5F9; margin: 0; padding: 20px;
  }
  .page { max-width: 460px; margin: 0 auto; }  /* centred, never too wide */

  .card {
    background: #fff;
    border: 1px solid #E3E9F0;
    border-left: 5px solid #E07B1E;            /* one coloured edge */
    border-radius: 12px;
    padding: 16px 20px;                        /* inside: content breathes */
    margin-bottom: 16px;                       /* outside: cards separate */
    box-shadow: 0 2px 8px rgba(16,32,64,.08);
  }
  .card h3 { margin: 0 0 4px; color: #0B2545; }
  .card p  { margin: 0; }

  .tag {
    display: inline-block;
    background: #E9F7E7; color: #0B6205;
    padding: 3px 12px;                          /* two values: 3 top/bottom, 12 sides */
    border-radius: 999px;                       /* a pill */
    font-size: 13px; font-weight: 700;
  }
</style>
<div class="page">
  <div class="card">
    <h3>CSE326 Internet Programming <span class="tag">Featured</span></h3>
    <p>In progress — Unit 3, Cascading Style Sheets.</p>
  </div>
  <div class="card">
    <h3>CSE305 Database Systems</h3>
    <p>Completed last semester.</p>
  </div>
</div>

  
Read the CSS and name each piece: the reset, the centred wrapper with a maximum width, padding inside the cards, margin between them, a one-sided border, a rounded pill, and a soft shadow. That is the whole box model doing ordinary work.






  
Exam-style checks

  
Which is the space INSIDE the border?L1

    
  • A. margin
  • B. padding
  • C. border-box
  • D. outline

    
Answer: B. Padding takes the background colour; margin is always transparent.

  
width: 200px, padding: 20px, border: 5px, no box-sizing. How wide is the element?L3

    
  • A. 200px
  • B. 225px
  • C. 250px
  • D. 245px

    
Answer: C. 200 + 20 + 20 + 5 + 5 = 250. With box-sizing: border-box it would be exactly 200.

  
What does box-sizing: border-box do?L2

    
  • A. Adds a border
  • B. Makes width include padding and border
  • C. Removes the margin
  • D. Centres the element

    
Answer: B. One line that removes an entire category of sizing bug, which is why it is usually applied to * at the top of a stylesheet.

  
In padding: 10px 20px, what does 20px apply to?L2

    
  • A. Top and bottom
  • B. Left and right
  • C. All sides
  • D. Right only

    
Answer: B. Two values mean top/bottom first, then left/right.

  
padding: 5px 10px 15px 20px applies 15px to which side?L3

    
  • A. Top
  • B. Right
  • C. Bottom
  • D. Left

    
Answer: C. Clockwise from the top: top, right, bottom, left. Remember TRouBLe.

  
How do you centre a fixed-width block horizontally?L2

    
  • A. text-align: center
  • B. margin: 0 auto with a width set
  • C. float: center
  • D. align: middle

    
Answer: B. auto splits the leftover space evenly on both sides, so there must be leftover space: the element needs a width narrower than its parent. text-align: center centres the content inside the box, not the box itself.

  
Which part of the box takes the background colour?L2

    
The content and the padding, out to the border. The margin is always transparent and shows whatever is behind the element.

  
border: 2px #E07B1E; shows nothing. Why?L3

    
The style is missing. border-style defaults to none, so a border with a width and a colour but no style is not drawn. Write border: 2px solid #E07B1E;.

  
Two stacked paragraphs each have margin: 20px 0. How big is the gap between them?L3

    
20px, not 40px. Vertical margins collapse: when two meet, the larger wins rather than the two adding up. It applies only to top and bottom margins, and does not happen inside a flex or grid container.

  
Which declaration makes a square element a circle?L2

    
border-radius: 50%; on an element with equal width and height. A large pixel value such as 999px turns a wide box into a pill instead.

  
Why prefer max-width: 800px to width: 800px on a page wrapper?L3

    
Because max-width allows the element to shrink. On a 375px phone, width: 800px forces a horizontal scrollbar; max-width: 800px simply becomes 375px wide. It is the single most useful responsive declaration.

  
What is the difference between border and outline?L3

    
A border is part of the box and takes up space, so adding one can shift the layout. An outline is drawn outside the border and takes no space, so it never moves anything — which is why browsers use it to show keyboard focus.
