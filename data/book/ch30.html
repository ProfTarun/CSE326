Flexbox Layout

Putting three cards in a row used to be the hardest easy thing in CSS. Flexbox solved it. Add one line to the parent and its children line up, space themselves out, centre perfectly and wrap onto a new line on a phone. This chapter gives you the five properties that do all of it, and the one idea — the two axes — that makes them make sense.

About 22 minutes · Course outcome CO3

Before you start — one-line reminders

  • Normal flow: block elements stack downwards, one per line (Chapter 29).
  • A parent contains children; the children are its direct descendants (Chapter 3).
  • box-sizing: border-box makes widths behave (Chapter 28).

By the end of this chapter you can

  • Turn any element into a flex container and say which elements become items.
  • Point at the main axis and the cross axis for any flex-direction.
  • Space and align items with justify-content, align-items and gap.
  • Centre something perfectly in two lines.
  • Make cards wrap onto a new line instead of squashing.

30.1 One line on the parent

Here is the whole idea. You have a container with some children. You write one declaration on the container:

.row { display: flex; }

Immediately the children stop stacking downwards and line up side by side. The container is now a flex container; its direct children are flex items. You did not touch the children at all.

<style>
  .row div { background: #FFF1E0; border: 1px solid #E07B1E;
             padding: 14px; border-radius: 8px; }
  .flex { display: flex; gap: 10px; }
</style>
<p><b>Without flex</b> — blocks stack downwards:</p>
<div class="row"><div>One</div><div>Two</div><div>Three</div></div>

<p><b>With display: flex</b> — the same three divs:</p>
<div class="row flex"><div>One</div><div>Two</div><div>Three</div></div>
The number one mistake. display: flex goes on the parent container, never on the children and never on body by accident. If you put it on each child, nothing lines up. Ask yourself: which element contains the things I want arranged? That one gets the declaration.

Flexbox is one-dimensional: it arranges items along a single line, either a row or a column. When you need rows and columns together, that is Grid (Chapter 31).

30.2 The one idea: two axes

Everything else in this chapter follows from this. A flex container has two directions:

  • The main axis — the direction the items flow in.
  • The cross axis — at right angles to it.

And the key point: which one is horizontal depends on flex-direction.

Picture this. Think of a train. justify-content decides how the carriages are spread along the track — bunched at the front, evenly spaced, pushed to the ends. align-items decides how they sit across the track — top, middle, bottom. Turn the track from horizontal to vertical and the two jobs stay the same; only the direction changed.

30.3 flex-direction

Controls whether items are arranged in a row or a column.

ValueItems flow
rowLeft to right. The default — you get it without writing anything.
columnTop to bottom
row-reverseRight to left
column-reverseBottom to top
Reversing is visual only. row-reverse changes the painted order, not the order in the HTML. Keyboard users still tab through the items in the original order, which can be genuinely confusing. If the order matters, change the HTML.

30.4 justify-content — spacing along the main axis

Once the items are on their line, justify-content decides how the leftover space is distributed.

Remember that justify-content always follows the main axis. With flex-direction: column, the main axis is vertical, so justify-content: center now centres the items vertically. Nothing changed about the property; the axis turned.

30.5 align-items — alignment along the cross axis

ValueIn a row, this means
stretchItems fill the container's height. The default, and the reason cards in a row come out equally tall for free.
flex-startAligned to the top
centerVertically centred
flex-endAligned to the bottom
baselineTheir first lines of text line up, whatever the box heights

Centring, at last

Centring something in the middle of a box used to need real hacks. Now it is two lines:

<style>
  .hero {
    display: flex;
    justify-content: center;   /* centre along the main axis: horizontally */
    align-items: center;       /* centre along the cross axis: vertically   */
    height: 150px;
    background: linear-gradient(135deg, #FF9933, #138808);
    border-radius: 12px;
  }
  .hero div { background: #fff; padding: 14px 22px; border-radius: 8px;
              font-weight: 700; color: #0B2545; }
</style>
<div class="hero"><div>Dead centre</div></div>

Those two declarations, on the parent, are worth memorising. They are the answer to "how do I centre a div", which is the most asked question in the history of CSS.

30.6 gap — space between items

gap puts space between flex items:

.row { display: flex; gap: 16px; }

Before gap existed, people used margin-right on each item and then wrote an extra rule to remove it from the last one, because otherwise there was a stray gap at the end. gap adds space only between items, never at the ends, so that problem disappears. Use it.

You can give two values: gap: 12px 20px means 12px between rows and 20px between columns.

30.7 Wrapping, and how items share space

  
flex-wrap

  
By default flex items never wrap. When the container gets narrower they shrink, and keep shrinking, until the text inside is one letter wide and the layout looks broken on a phone.

  
flex-wrap: wrap lets them move onto a new line instead:

  
<style>
  .row { display: flex; flex-wrap: wrap; gap: 12px; }
  .row div {
    flex: 1 1 180px;              /* grow, shrink, but never below 180px */
    background: #fff; border: 1px solid #E3E9F0; border-radius: 10px;
    padding: 14px;
  }
</style>
<div class="row">
  <div><b>CSE326</b><br>Internet Programming</div>
  <div><b>CSE305</b><br>Database Systems</div>
  <div><b>CSE201</b><br>Data Structures</div>
</div>

  
The flex shorthand on items

  
Everything so far went on the container. flex is the one property you put on the items, and it takes three values:

  
flex: 1 1 180px;
/*    | |  |
      | |  flex-basis:  the starting size
      | flex-shrink: may it get smaller? (1 = yes)
      flex-grow:   may it get bigger?  (1 = yes)   */

  

    
WrittenMeans

    
      
flex: 1Share the space equally with the other flex: 1 items. The one you will use most.

      
flex: 2Take twice as much space as a flex: 1 item

      
flex: 0 0 200pxExactly 200px, never grow, never shrink — a fixed sidebar

      
flex: 1 1 180pxStart at 180px, then grow or shrink as room allows

    
  

  
<style>
  .layout { display: flex; gap: 14px; }
  .side { flex: 0 0 140px; background: #FFF1E0; padding: 14px; border-radius: 10px; }
  .main { flex: 1;          background: #fff; padding: 14px; border-radius: 10px;
          border: 1px solid #E3E9F0; }
</style>
<div class="layout">
  <div class="side">Sidebar<br><small>always 140px</small></div>
  <div class="main">Main content<br><small>takes whatever is left</small></div>
</div>






  
30.8 Build it: the navigation bar and the course row

  
Two patterns you will use in every project you ever build.

  
<style>
  * { box-sizing: border-box; }
  body { font-family: system-ui, sans-serif; margin: 0; background: #F1F5F9;
         color: #3C4A60; }

  /* --- the navigation bar: logo left, links right --- */
  .nav {
    display: flex;
    justify-content: space-between;   /* push the two groups apart */
    align-items: center;              /* line them up vertically   */
    gap: 16px;
    background: #0B2545; color: #fff; padding: 12px 20px;
  }
  .nav .links { display: flex; gap: 18px; }   /* a flex container inside a flex item */
  .nav a { color: #fff; text-decoration: none; }

  /* --- the course row: three cards that wrap on a phone --- */
  .row { display: flex; flex-wrap: wrap; gap: 14px; padding: 20px; }
  .card {
    flex: 1 1 200px;                  /* grow, shrink, never below 200px */
    background: #fff; border-radius: 12px; padding: 16px;
    box-shadow: 0 2px 8px rgba(16,32,64,.08);
  }
  .card h3 { margin: 0 0 6px; color: #0B2545; font-size: 16px; }
  .card p  { margin: 0; font-size: 14px; }
</style>
<div class="nav">
  <b>Asha Kumar</b>
  <span class="links"><a href="#">Courses</a><a href="#">Skills</a><a href="#">Contact</a></span>
</div>
<div class="row">
  <div class="card"><h3>CSE326</h3><p>Internet Programming</p></div>
  <div class="card"><h3>CSE305</h3><p>Database Systems</p></div>
  <div class="card"><h3>CSE201</h3><p>Data Structures</p></div>
</div>

  
Drag the preview narrow. The cards wrap, the nav stays put, and you wrote no media query at all. Notice too that a flex item can itself be a flex container — that is how the links group works.






  
Exam-style checks

  
Where do you put display: flex?L1

    
  • A. On each child
  • B. On the parent container
  • C. On the body
  • D. In a media query

    
Answer: B. The children then become flex items automatically; you do not style them to make it work.

  
Which property spaces items along the MAIN axis?L2

    
  • A. align-items
  • B. justify-content
  • C. flex-wrap
  • D. gap

    
Answer: B. align-items works along the cross axis.

  
With flex-direction: column, justify-content now controls:L3

    
  • A. Horizontal position
  • B. Vertical position
  • C. Nothing
  • D. The order of items

    
Answer: B. justify-content always follows the main axis, and in a column the main axis is vertical.

  
Which centres content both horizontally and vertically?L2

    
  • A. text-align: center only
  • B. display: flex with justify-content: center and align-items: center
  • C. margin: auto only
  • D. float: center

    
Answer: B. Two lines on the parent, and they replaced years of genuine hacks. (float: center does not exist.)

  
Why prefer gap over margins between flex items?L2

    
  • A. It is newer
  • B. gap adds space only BETWEEN items, not at the ends
  • C. Margins do not work
  • D. gap is faster

    
Answer: B. There is no leftover edge space to cancel out with an extra rule for the last child.

  
Cards squash instead of moving to a new line on a phone. What is missing?L3

    
  • A. flex: 1
  • B. flex-wrap: wrap
  • C. gap
  • D. align-items

    
Answer: B. Without wrap, flex items shrink indefinitely on one line. Pair it with flex: 1 1 200px so each card has a sensible minimum.

  
What is the default flex-direction, and what is the default align-items?L2

    
row and stretch. That is why three cards in a flex row come out equally tall without you asking — they stretch to the height of the tallest.

  
Which justify-content value puts the first item at the left edge, the last at the right, and equal gaps between?L2

    
space-between. It is the standard way to build a navigation bar with a logo on the left and links on the right.

  
What does flex: 1 on an item mean?L2

    
"Grow to share the available space equally with the other flex: 1 items." Give one item flex: 2 and it takes twice the share. flex: 0 0 140px means a fixed 140px that neither grows nor shrinks.

  
Flexbox is for one dimension. What is Grid for?L2

    
Rows AND columns together — a two-dimensional layout (Chapter 31). Flex for a line, Grid for a grid.
