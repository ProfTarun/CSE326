Lists

Menus, steps, features, requirements, glossaries: a surprising amount of every page is a list. HTML has three list types, each with a precise meaning, and a strict rule about what may sit inside them. This chapter covers all three, the attributes that control numbering, how to nest lists correctly, and why a navigation menu should be a list even when its bullets are hidden.

About 13 minutes · Course outcome CO1

By the end of this chapter you can

  • Choose between ul, ol and dl by the meaning of the content.
  • Write valid list markup: only li directly inside ul/ol; dt/dd inside dl.
  • Nest a sub-list in the right place.
  • Use type, start and reversed on ordered lists.
  • Explain why screen-reader users benefit from lists.

7.1 Three kinds of list

Unordered list: <ul> + <li>

Use it for a set of related items whose order carries no meaning: a list of skills, the ingredients you need, the links in a menu. Each item is an <li> (list item). Browsers show bullets by default.

<ul>
  <li>HTML5</li>
  <li>CSS3</li>
  <li>JavaScript</li>
</ul>

Ordered list: <ol> + <li>

Use it when the sequence carries meaning: the steps to install an editor in the order they must be performed, a recipe, a ranking of the top five students, the stages of an exam. Browsers number the items automatically, so you never type the numbers yourself; insert a step and the rest renumber.

<ol>
  <li>Open VS Code</li>
  <li>Create index.html</li>
  <li>Write HTML code</li>
</ol>

Description list: <dl> + <dt> + <dd>

A description list pairs terms with descriptions. <dl> is the list, <dt> (description term) names a term, and <dd> (description details) describes it. Use it for glossaries, dictionaries, FAQ-style question-and-answer pairs and key–value metadata (Name: Rahul, Course: CSE326). Note that <dl> does not use <li>: the pair <dt>/<dd> structures a term with its description.

<dl>
  <dt>HTML</dt>
  <dd>Structures web content.</dd>
  <dt>CSS</dt>
  <dd>Styles web content.</dd>
</dl>

7.2 The one strict rule: what goes inside a list

Only <li> elements may sit directly inside a <ul> or <ol>. Loose text, a <p>, a <div> or a link placed directly inside the list is invalid. Anything you want in the list goes inside an <li>, and an <li> can hold anything: text, links, images, paragraphs, even another list.

✗ Loose content inside the list
<ul>
  Web
  <li>HTML</li>
  <p>CSS</p>
</ul>
"Web" and the paragraph are not list items.
✓ Everything wrapped in li
<ul>
  <li>Web</li>
  <li>HTML</li>
  <li><p>CSS</p></li>
</ul>

7.3 Nested lists

A list can contain another list, which is how outlines, multi-level menus and course syllabuses are written. The rule follows from the previous section: the sub-list describes one item, so it goes inside that item's <li>, after the item's text and before its closing </li>. It does not go directly inside the parent <ul>, and not after the parent list has closed.

<ul>
  <li>Frontend
    <ul>
      <li>HTML</li>
      <li>CSS</li>
    </ul>
  </li>
  <li>Backend</li>
</ul>
✗ Sub-list dropped straight into the parent ul
<ul>
  <li>Web</li>
  <ul><li>HTML</li></ul>
</ul>
A ul is not an li, so it may not be a direct child of ul. (Also invalid: <li><ul>Web<li>HTML</li></ul></li>, which puts loose text inside the inner ul.)
✓ Sub-list inside the item
<ul>
  <li>Web
    <ul><li>HTML</li></ul>
  </li>
</ul>

7.4 Controlling ordered lists: type, start and reversed

Ordered lists take three attributes. They change the numbering; they never change the order of the items in your markup.

AttributeEffectExample
type="1"Decimal numbers (the default): 1, 2, 3<ol type="1">
type="a"Lowercase letters: a, b, c<ol type="a">
type="A"Uppercase letters: A, B, C<ol type="A">
type="i"Lowercase Roman numerals: i, ii, iii<ol type="i">
type="I"Uppercase Roman numerals: I, II, III<ol type="I">
start="5"Begin counting at 5 (5, 6, 7 ...)<ol start="5">
reversedCount downwards (3, 2, 1); a boolean attribute. The items stay in source order on screen; only the numbers descend<ol reversed>
 
<ol type="I">
  <li>Introduction</li><li>Method</li><li>Results</li>
</ol>
<ol type="a" start="5">
  <li>fifth item, lettered e</li><li>sixth item, lettered f</li>
</ol>
<ol reversed>
  <li>Gold</li><li>Silver</li><li>Bronze</li>
</ol>

A single item can also set its own number with <li value="10">; later items continue from it. Unordered lists have no numbering to control; their bullet style is changed with CSS (list-style-type), not with attributes.

7.5 Choosing the right list

  • Steps to install an editor, in the order they must be performed: ol, because the sequence carries meaning.
  • A set of skills where the order carries no meaning: ul.
  • A term paired with its definition: dl with dt and dd.
  • A ranking of the top five students: ol (the position is the information).

7.6 Lists as navigation, and why the bullets do not matter

Almost every site's menu is a <ul> of links inside a <nav>, with the bullets removed by CSS. If the bullets are hidden, why bother with the list? Because the list is information, not decoration. A screen reader announces "list, five items" when it reaches a ul, so the user knows exactly how many choices there are and can skip the whole group in one keystroke. Five loose links tell them nothing. The list also gives CSS a clean structure to lay out horizontally (Unit 3). Marking a menu as a list is not required by HTML and does not load faster; it is done for the semantics.

<nav aria-label="Main">
  <ul>
    <li><a href="index.html">Home</a></li>
    <li><a href="courses.html">Courses</a></li>
    <li><a href="contact.html">Contact</a></li>
  </ul>
</nav>

Exam-style checks

A page lists the steps to install an editor, in the order they must be performed. Which list is correct?L2
  • A. <ul>, because the items are related
  • B. <dl>, because each step has a description
  • C. <ol>, because the sequence carries meaning
  • D. <table>, because the steps are numbered

Answer: C. Order matters, so ordered list. Numbering is not a reason for a table.

Which content is best represented by an unordered list?L2
  • A. The steps of a recipe in cooking order
  • B. A ranking of the top five students
  • C. A set of skills where the order carries no meaning
  • D. A term paired with its definition

Answer: C. A and B need ol; D needs dl.

Which tag creates a NUMBERED list?L1

Answer: <ol> (ordered). ul is bulleted, dl is a description list, and there is no list element.

Which pair of tags structures a term together with its description?L1
  • A. <ul> and <li>
  • B. <dl> and <li>
  • C. <ol> and <li>
  • D. <dt> and <dd>

Answer: D. dt names the term, dd describes it, both inside dl. dl never uses li.

Which element defines a term inside a <dl>?L1

Answer: <dt>. dd is its description.

Which elements may sit DIRECTLY inside a <ul>?L2
  • A. Any element
  • B. Only <li>
  • C. <li> and <p>
  • D. <li> and <div>

Answer: B. Loose text or other elements placed directly inside a list are invalid; put them inside an li.

Which nesting of a sublist is valid HTML?L3
  • A. <li><ul>Web<li>HTML</li></ul></li>
  • B. <ul><ul><li>HTML</li></ul></ul>
  • C. <ul><li>Web</li><ul><li>HTML</li></ul></ul>
  • D. <ul><li>Web<ul><li>HTML</li></ul></li></ul>

Answer: D. The inner ul is inside the li for "Web". A has loose text inside a ul; B and C put a ul directly inside a ul.

Where must a nested list be placed?L2

Answer: inside an <li> of the parent list, before that item's closing tag. Not directly inside the parent ul, not after it closes, and not inside a dd (unless it is a description list).

What does <ol type="I"> produce as list markers?L1
  • A. 1, 2, 3
  • B. i, ii, iii
  • C. I, II, III
  • D. A, B, C

Answer: C. Uppercase I gives uppercase Roman numerals; lowercase i gives lowercase ones.

<ol type="a"> produces markers that look like:L1

Answer: a, b, c. Lowercase type="a" gives lowercase letters; type="A" gives capitals.

Which attribute makes an ordered list start at 5?L1

Answer: start="5": <ol start="5">. begin, from and index do not exist.

What is the effect of writing <ol reversed>?L2
  • A. The list counts downwards instead of upwards
  • B. The list items appear in reverse order on screen
  • C. The list markers change to Roman numerals
  • D. The list becomes unordered

Answer: A. Items stay in source order; only the numbers descend (3, 2, 1).

Why mark a navigation menu as a list even though CSS removes the bullets?L2
  • A. It is required by HTML
  • B. So a screen reader announces the item count
  • C. It loads faster
  • D. Bullets cannot be removed otherwise

Answer: B. "List, five items" tells the user how many choices there are; loose links do not.

Quick revision

Key takeaways

  1. ul: order does not matter. ol: order or rank matters. dl: terms (dt) with descriptions (dd).
  2. Only li may sit directly inside ul or ol; anything else goes inside an li.
  3. A nested list goes inside the li it belongs to, before that li closes.
  4. ol attributes: type (1, a, A, i, I), start="n", reversed (counts down; items stay in place). li value="n" sets one item's number.
  5. Menus are lists of links inside nav: screen readers announce the item count.
