Input Types and Attributes

One element, <input>, becomes twenty different controls depending on its type: a text box, a password field, a date picker, a colour picker, a slider, a file chooser, a checkbox. Choosing the right type gives you the right keyboard on a phone, the right validation and the right assistive-technology behaviour for free. This chapter is a complete tour of the types and of the attributes that configure them, with every control live on the page so you can try it.

Date and time controls also accept min and max (min="2026-01-01"), so a booking form can refuse past dates without any script.

17.3 Choices: checkbox and radio

Checkbox: independent yes/no choices

type="checkbox" creates a box the user can tick to select zero, one or many options; each box is an independent choice. Several checkboxes may share the same name: that is valid, and they submit together as a set of values (skills=html&skills=css). checked pre-ticks a box. Remember from Chapter 16 that an unticked checkbox sends nothing at all.

Radio: exactly one of a group

type="radio" creates buttons of which only one in a group can be selected: the right control when the user must choose exactly one spice level, one gender, one year of study. What makes them a group is the shared name. Three radios with the same name behave as one mutually exclusive set. Three radios each with a different name are three separate groups of one, so all three can be selected at once, which is a bug you will see in the lab. Each button carries its own value; checked pre-selects one when the page loads; and a fieldset/legend should wrap the group so the question is announced with the options.

17.4 Files and buttons

type="file" lets the user attach a document from their device (a resume, an assignment, a photo). Its accept attribute restricts the file types offered in the picker: accept=".pdf,.jpg" or accept="image/*"; multiple allows more than one file. The form must use method="post" and enctype="multipart/form-data" for the file to be uploaded.

Three input types are buttons: type="submit" submits the form; type="reset" restores every control to its initial value; type="button" does nothing until a script gives it a job. The button's caption is its value. In modern code <button> is usually preferred because it can contain other elements, but the types are identical (Chapter 16). There is also type="image", a graphical submit button.

Two pairs that are always examined. readonly versus disabled: both stop editing, but readonly is submitted and disabled is not (and disabled is greyed out). min/max versus minlength/maxlength: min and max bound the value of a number or date; minlength and maxlength bound the length of text in characters.

Exam-style checks

Which input type masks the typed characters as dots?L1
  • A. type="hidden"
  • B. type="secret"
  • C. type="password"
  • D. type="mask"

Answer: C. hidden is invisible, not masked.

Which input type makes a phone show an @ key, and which should be used for a phone number so that mobile keyboards adapt?L2

Answer: type="email" for the @ keyboard and validation; type="tel" for a phone number (numeric keypad, no spinner, allows + and leading zeros). phone, mobile and mail do not exist.

Which input type is intended for entering a website address?L1
  • A. type="web"
  • B. type="link"
  • C. type="url"
  • D. type="href"

Answer: C.

Which input type presents a numeric field with an up/down spinner, and which attributes constrain it to values between 18 and 60?L2

Answer: type="number" with min="18" max="60". minlength/maxlength bound length, not value; start/end and range="18-60" do not exist.

What does the step attribute do on <input type="number">?L2
  • A. It sets the lowest value that may be entered
  • B. It defines the legal interval between accepted values
  • C. It counts how many times the field may be edited
  • D. It limits the number of digits allowed

Answer: B.

Which input type gives the user a native calendar picker, and which lets a user choose a month and year together?L2

Answer: type="date" and type="month". week picks a week; period does not exist.

Which input type opens a native colour picker, and which presents a slider?L1

Answer: type="color" and type="range". paint, palette, picker, slider and scale do not exist.

Which input type creates a field styled as a search box?L1

Answer: type="search".

Which input type lets the user attach a document from their device, and which attribute restricts the file types offered?L2

Answer: type="file" with accept (e.g. accept=".pdf,.jpg"). Add multiple to allow more than one file.

A form asks the user to choose exactly one spice level from four options. Which control is correct?L2
  • A. <input type="radio">
  • B. <input type="checkbox">
  • C. <select multiple>
  • D. <input type="range">

Answer: A. Radio buttons sharing one name allow exactly one choice.

Four radio buttons must behave as one mutually exclusive group. They must share the same:L3
  • A. id
  • B. name
  • C. class
  • D. value

Answer: B. ids must be unique; values should differ; the shared name makes the group.

Three radio buttons each have a DIFFERENT name. What happens?L3

Answer: all three can be selected at once, because each is its own group of one.

Which input type creates a box the user can tick to select zero, one or many options, and is it valid for two checkboxes to share the same name?L2

Answer: type="checkbox"; yes, same-named checkboxes are valid and submit together as a set of values.

Which attribute pre-selects one radio button (or pre-ticks a checkbox), and which pre-selects an option?L2

Answer: checked for radio and checkbox; selected for option.

Which attribute keeps a field visible and submitted but prevents the user from editing it, and which both greys out a control and stops its value being submitted?L2

Answer: readonly (submitted, not editable) and disabled (greyed out, not submitted).

In <input type="password" minlength="8" required>, what does minlength enforce?L3
  • A. The value must contain at most 8 characters
  • B. The value must contain at least 8 characters
  • C. The field must be filled within 8 seconds
  • D. The password must contain exactly 8 digits

Answer: B.

Which attribute caps the number of characters a user may type into a text field, and which pair limits how many characters may be typed?L2

Answer: maxlength; the pair is minlength and maxlength. min/max bound the value; size is only the visible width.

Which attribute sets the visible width of a text input in characters?L1
  • A. maxlength
  • B. width
  • C. size
  • D. cols

Answer: C. cols is for textarea; maxlength limits input rather than width.

Which attribute gives a form control keyboard focus automatically as the page loads?L2
  • A. default
  • B. focus
  • C. autoselect
  • D. autofocus

Answer: D.

Which attribute blocks submission while a field is still empty, and which pre-fills a default entry into a text input?L1

Answer: required and value. placeholder is only a hint.

Which input type produces a button that submits the form when clicked?L1
  • A. type="submit"
  • B. type="button"
  • C. type="send"
  • D. type="reset"

Answer: A.

Which is the most accessible way to label a radio button?L2

Answer: a <label> using for/id, or wrapping the input inside the label; loose text next to it, a placeholder or a title is not associated with the control.

Quick revision

Key takeaways

  1. Text-like: text, password (masked), email (@ keyboard, validation), url, tel (numeric keypad), search, number (spinner, min/max/step), hidden.
  2. Pickers: date, time, datetime-local, month, week, color; range is a slider.
  3. radio = exactly one of a group defined by a shared name; different names = separate groups; checked pre-selects. checkbox = independent, any number; same name is fine.
  4. file with accept (and multiple); submit / reset / button (button does nothing alone).
  5. placeholder (hint, vanishes), value (pre-fill / data), required, readonly (submitted), disabled (not submitted), checked / selected, multiple, min / max / step (value), minlength / maxlength (length), size (visible width), autofocus, autocomplete.
