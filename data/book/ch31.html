CSS Grid Layout

Flexbox arranges things along a line. Grid arranges them in rows and columns at the same time — a real two-dimensional layout, drawn on the page like a plan. It is the tool for page structure: a header, a sidebar, a main area and a footer, described in a few lines that read almost like a picture.

About 24 minutes · Course outcome CO3 · Builds on Chapter 30

Before you start — one-line reminders

  • display: flex goes on the parent; its children become items (Chapter 30).
  • gap puts space between items and not at the ends (Chapter 30).
  • % is a share of the parent; px is fixed (Chapter 25).

By the end of this chapter you can

  • Say when to reach for Grid and when for Flexbox.
  • Define columns and rows, and explain what fr means.
  • Use repeat(), minmax() and auto-fit to build a responsive grid with no media query.
  • Make one item span several columns or rows.
  • Lay out a whole page with named areas.

31.1 One dimension or two

Both Flexbox and Grid are switched on with one declaration on the parent, and both arrange children. The difference is how many directions you are controlling at once.

Laying out a navigation bar, a row of tags or a card's inner parts? Flexbox. Laying out the page itself, or a gallery where everything must line up in both directions? Grid. They work happily together: a grid cell often contains a flex container.

31.2 Columns, and the fr unit

Two declarations get you a grid:

.grid {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;   /* three equal columns */
}

grid-template-columns defines the number and size of the columns. You write one value per column, so three values means three columns.

What is fr?

fr is a unit that exists only in Grid. It means one share of the leftover space. The browser measures what space remains after any fixed sizes and gaps, then divides it into shares.

WrittenResult
1fr 1frTwo equal columns, half each
2fr 1frThree shares in total: the first column gets two of them, the second gets one
200px 1frA fixed 200px sidebar, and the rest for the main area
1fr 1fr 1frThree equal columns

Why not use percentages? Because 33.33% × 3 plus a gap adds up to more than 100% and overflows. fr shares out what is actually left after the gaps, so it always fits.

<style>
  .grid { display: grid; gap: 10px; margin-bottom: 14px; }
  .g1 { grid-template-columns: 1fr 1fr 1fr; }
  .g2 { grid-template-columns: 2fr 1fr; }
  .g3 { grid-template-columns: 180px 1fr; }
  .grid div { background: #FFF1E0; border: 1px solid #E07B1E;
              padding: 12px; border-radius: 8px; text-align: center; }
</style>
<div class="grid g1"><div>1fr</div><div>1fr</div><div>1fr</div></div>
<div class="grid g2"><div>2fr</div><div>1fr</div></div>
<div class="grid g3"><div>180px</div><div>1fr</div></div>

Rows

grid-template-rows does the same for row heights. You often leave it out: rows are created automatically as items need them, and their height comes from the content, which is usually what you want.

.grid {
  display: grid;
  grid-template-columns: 1fr 1fr;
  grid-template-rows: 80px auto;   /* a fixed first row, then as tall as needed */
  gap: 12px;
}

31.3 repeat(), minmax() and the responsive grid

repeat()

Writing 1fr 1fr 1fr 1fr 1fr 1fr is tedious. repeat() says it once:

grid-template-columns: repeat(6, 1fr);      /* six equal columns   */
grid-template-columns: repeat(3, 200px);    /* three 200px columns */

minmax()

minmax(min, max) gives a column a floor and a ceiling: minmax(200px, 1fr) means "at least 200px wide, but take a share of the leftover space if there is any".

auto-fit: a responsive gallery in one line

Now put them together. This is the single most useful line in modern CSS layout:

grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));

Read it as an instruction to the browser: "Fit as many columns as you can. Each one must be at least 200px. Share any leftover space equally between them."

The result: three columns on a laptop, two on a tablet, one on a phone — and you wrote no media query at all. The browser recalculates as the window changes.

<style>
  .gallery {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(160px, 1fr));
    gap: 12px;
  }
  .gallery div {
    background: #fff; border: 1px solid #E3E9F0; border-radius: 10px;
    padding: 16px; text-align: center; font-weight: 700; color: #0B2545;
  }
</style>
<div class="gallery">
  <div>HTML</div><div>CSS</div><div>JavaScript</div>
  <div>React</div><div>Git</div><div>SQL</div>
</div>

auto-fill is the close relative of auto-fit. The difference only shows when there are too few items to fill a row: auto-fit stretches the items you have to fill the width, while auto-fill keeps the empty columns reserved. auto-fit is usually what you want.

31.4 Making an item span more than one cell

  
By default each item drops into the next free cell. grid-column and grid-row let one item take more room.

  
The easiest form uses the keyword span:

  
.wide { grid-column: span 2; }   /* take two columns */
.tall { grid-row: span 2; }      /* take two rows    */

  
The longer form names the grid lines. In a three-column grid there are four vertical lines, numbered 1 to 4 from the left. grid-column: 1 / 3 means "start at line 1, end at line 3", which covers the first two columns. grid-column: 1 / -1 is a handy shortcut meaning "from the first line to the last" — the full width, whatever the column count.

  
  
<style>
  .grid { display: grid; grid-template-columns: repeat(3, 1fr); gap: 12px; }
  .grid div { background: #fff; border: 1px solid #E3E9F0; border-radius: 10px;
              padding: 14px; text-align: center; }
  .feature { grid-column: 1 / -1;          /* the whole width */
             background: #FFF8F0 !important; border-color: #E07B1E !important;
             font-weight: 700; }
  .tall { grid-row: span 2; }
</style>
<div class="grid">
  <div class="feature">Featured course — spans every column</div>
  <div class="tall">Tall<br>(two rows)</div>
  <div>CSE305</div><div>CSE201</div>
  <div>MTH101</div><div>PHY104</div>
</div>






  
31.5 Named areas: a layout you can read

  
This is the feature that makes Grid a joy. You draw the layout as text, then say which element goes in which named area.

  
<style>
  .page {
    display: grid;
    grid-template-columns: 180px 1fr;
    grid-template-areas:
      "head head"
      "side main"
      "foot foot";
    gap: 10px;
    min-height: 260px;
  }
  .page > * { padding: 12px; border-radius: 8px; color: #fff; font-weight: 700; }
  .head { grid-area: head; background: #0B2545; }
  .side { grid-area: side; background: #E07B1E; }
  .main { grid-area: main; background: #138808; }
  .foot { grid-area: foot; background: #6B7A90; }
</style>
<div class="page">
  <div class="head">header</div>
  <div class="side">sidebar</div>
  <div class="main">main content</div>
  <div class="foot">footer</div>
</div>

  
Look at the grid-template-areas block. It is the layout: three rows, two columns, with head and foot stretching across both. A repeated name means "this area continues here". You can read the page shape without running it.

  
And rearranging for a phone is three lines — the HTML never changes:

  
@media (max-width: 600px) {
  .page {
    grid-template-columns: 1fr;       /* one column */
    grid-template-areas: "head" "main" "side" "foot";
  }
}

  
Notice that on a phone the main content has been moved above the sidebar, purely in CSS. Chapter 37 covers media queries properly.






  
31.6 Aligning inside a grid

  
Grid uses the same alignment vocabulary as Flexbox, with one addition: because there are two axes, there are two sets of properties.

  

    
PropertyAlignsAlong

    
      
justify-itemsEach item inside its own cellThe row direction (left/right)

      
align-itemsEach item inside its own cellThe column direction (up/down)

      
justify-contentThe whole grid inside the containerLeft/right, when the grid is narrower than the box

      
align-contentThe whole grid inside the containerUp/down

      
place-items: centerShorthand for align-items + justify-itemsBoth — dead centre in every cell

    
  

  
display: grid; place-items: center; is the shortest way to centre one thing inside a box — two declarations instead of Flexbox's three.






  
31.7 Build it: the profile page skeleton

  
<style>
  * { box-sizing: border-box; }
  body { font-family: system-ui, sans-serif; margin: 0; padding: 16px;
         background: #F1F5F9; color: #3C4A60; }

  /* --- the page: Grid --- */
  .page {
    display: grid;
    grid-template-columns: 200px 1fr;
    grid-template-areas: "profile courses" "profile skills";
    gap: 14px;
    align-items: start;
  }
  .profile { grid-area: profile; }
  .courses { grid-area: courses; }
  .skills  { grid-area: skills;  }

  .panel { background: #fff; border-radius: 12px; padding: 16px;
           box-shadow: 0 2px 8px rgba(16,32,64,.08); }
  h2 { margin: 0 0 10px; font-size: 16px; color: #0B2545; }

  /* --- the course cards: Grid again, responsive with no media query --- */
  .cards {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(140px, 1fr));
    gap: 10px;
  }
  .cards div { background: #FFF8F0; border: 1px solid #F0C79A;
               border-radius: 8px; padding: 10px; font-size: 14px; }

  /* --- the skill tags: Flexbox, because they are one line of things --- */
  .tags { display: flex; flex-wrap: wrap; gap: 8px; }
  .tags span { background: #E9F7E7; color: #0B6205; padding: 4px 12px;
               border-radius: 999px; font-size: 13px; font-weight: 700; }
</style>
<div class="page">
  <div class="panel profile"><h2>Asha Kumar</h2><p style="margin:0;font-size:14px">B.Tech CSE, first year.</p></div>
  <div class="panel courses"><h2>Courses</h2>
    <div class="cards"><div>CSE326</div><div>CSE305</div><div>CSE201</div></div>
  </div>
  <div class="panel skills"><h2>Skills</h2>
    <div class="tags"><span>HTML</span><span>CSS</span><span>JavaScript</span><span>React</span></div>
  </div>
</div>

  
That page uses Grid twice and Flexbox once, each for the job it suits: Grid for the page plan and the card gallery, Flexbox for the single line of tags. That is exactly how professional stylesheets are written.






  
Exam-style checks

  
What does the fr unit mean in Grid?L2

    
  • A. Fixed rem
  • B. One share of the leftover space
  • C. Frame
  • D. Fraction of the viewport

    
Answer: B. 1fr 1fr splits the space evenly; 2fr 1fr gives the first column twice as much.

  
What does repeat(auto-fit, minmax(200px, 1fr)) achieve?L3

    
  • A. Exactly 200px columns
  • B. As many columns as fit, each at least 200px, sharing the space
  • C. 200 columns
  • D. A single flexible column

    
Answer: B. A responsive grid with no media query at all — three columns on a laptop, one on a phone.

  
Flexbox is for one dimension. Grid is for:L2

    
  • A. One dimension too
  • B. Rows AND columns together
  • C. Only tables
  • D. Only images

    
Answer: B. Flex for a line; Grid for a two-dimensional layout. They are often used together.

  
Which property defines the number and size of the grid's columns?L1

    
grid-template-columns. One value per column, so 1fr 1fr 1fr creates three equal columns. grid-template-rows does the same for row heights.

  
Where does display: grid go?L1

    
On the parent container, exactly like display: flex. Its direct children become grid items automatically.

  
Why use 1fr 1fr 1fr rather than 33.33% 33.33% 33.33%?L3

    
Because percentages do not account for the gap. Three 33.33% columns plus two gaps add up to more than the container and overflow. fr divides the space that is actually left after the gaps, so it always fits.

  
Which declaration makes a grid item stretch across two columns?L2

    
grid-column: span 2;, or the line form grid-column: 1 / 3. grid-column: 1 / -1 means all the way across, whatever the column count.

  
What does minmax(200px, 1fr) mean?L2

    
"Never narrower than 200px, but take a share of the leftover space when there is any." It is what stops a responsive grid squeezing its columns into unusable slivers.

  
What does grid-template-areas let you do?L3

    
Name regions of the grid and draw the layout as text, then place each element with grid-area. Rearranging the page for a phone then means rewriting a few lines of CSS, with no change to the HTML.

  
You need a navigation bar with a logo on the left and links on the right. Grid or Flexbox?L3

    
Flexbox — it is a single line of items, so display: flex; justify-content: space-between; is the natural fit. Save Grid for layouts where things must line up in two directions.
