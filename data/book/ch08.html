Hyperlinks and Images

Links are what make the Web a web, and images are what make it worth looking at. This chapter covers the anchor element and every kind of URL it can point to, the rules for relative paths that break so many deployed sites, the image element and the art of writing alt text, and the HTML5 tools for responsive images.

About 23 minutes · Course outcome CO1

By the end of this chapter you can

  • Write links to other pages, to places on the same page, to email addresses and phone numbers.
  • Resolve relative paths, including ../ and root-relative /.
  • Use target, rel, download and title correctly and safely.
  • Embed images with src, alt, width, height and loading, and write good alt text for every kind of image.
  • Use figure/figcaption, picture, srcset and sizes.

8.1 The anchor element

A hyperlink is created with the anchor element, <a>. Its href attribute (hypertext reference) holds the destination; the content between the tags is the clickable text. Without an href an anchor is just text: it goes nowhere.

<p>Read the <a href="https://developer.mozilla.org/">MDN documentation</a> for every element.</p>

Do not confuse <a> with <link>: <link> lives in the head and attaches a stylesheet or icon; it never creates a clickable link. And there is no <href> or <url> element.

8.2 What href can point to

Absolute URLs: another site

An absolute URL includes the protocol and domain: <a href="https://github.com">GitHub</a>. Use it for external sites. It means the same thing wherever it is written.

Relative URLs: your own pages

A relative URL omits the protocol and domain and is resolved against the address of the page it appears on. Within your own site always use relative links: they are shorter, they work on your laptop and on the live server alike, and the whole site can move to another domain without editing a single link.

  • about.html: a file in the same folder as the current page.
  • images/campus.jpg: inside a sub-folder of the current folder.
  • ../about.html: ../ moves up to the parent directory, then finds the file there. It does not mean the site root and it does not mean an external site.
  • /index.html: a leading slash means start from the site root, whatever folder the current page is in.
The GitHub Pages trap. A site that works on your laptop but whose links and images all break once deployed almost always has one of two bugs: wrong relative paths (a path that worked because of where you opened the file locally), or capitalisation. Windows ignores case, but the web server is case-sensitive: About.html and about.html, Photo.JPG and photo.jpg, are different files there. Keep every file name lowercase and check each path.

Fragment links: a place on the same page

href="#contact" jumps to the element on the current page whose id is contact. It needs two halves: the link, and an element with the matching id. If no element has id="contact", the click silently does nothing. You can combine a page and a fragment: about.html#team.

<p><a href="#contact">Go to the contact section</a></p>
<p style="height: 300px">(imagine a long page here)</p>
<section id="contact">
  <h2>Contact</h2>
  <p>cse326@example.edu</p>
</section>

Email and telephone links

Two special schemes hand the link to another application. href="mailto:help@example.com" opens the user's email client with a new message addressed to that address. href="tel:+919876543210" lets a mobile user dial the number with one tap. The schemes are exactly mailto: and tel:; there is no email:, mail:, call: or phone:.

<a href="mailto:help@example.com">Email the helpdesk</a>
<a href="tel:+911234567890">Call the helpdesk</a>

8.3 target, rel, download and title

target="_blank"
Opens the link in a new tab (a new browsing context). The default, target="_self", opens it in the same tab. Use a new tab sparingly and deliberately: users expect links to stay in the tab unless there is a reason.
rel="noopener noreferrer"
rel describes the relationship between the current page and the linked document. Its most important use: when you open untrusted content with target="_blank", add rel="noopener noreferrer". Without noopener, the new page can reach back through window.opener and script your tab, for example replacing it with a fake login page. noreferrer also stops the new site learning which page you came from. It does not make the link load faster and is not needed for the link to work; it is a safety measure.
download
Prompts the browser to save the linked file instead of opening it: <a href="syllabus.pdf" download>Download the syllabus</a>. An optional value suggests a file name.
title
Advisory text shown as a tooltip when hovering. It is a supplement; never rely on it to explain a link, because touch-screen and keyboard users may never see it.
<a href="https://example.com" target="_blank" rel="noopener noreferrer">Open example.com in a new tab</a>
<br>
<a href="data:text/plain,Hello%20CSE326" download="hello.txt">Download a text file</a>

Link text that works

Link text should describe the destination. Screen-reader users often list all the links on a page; "click here, here, more, >>" tells them nothing, while "View our pricing plans" tells them everything. Search engines use link text the same way. So <a href="pricing.html">View our pricing plans</a> beats "Click here", "More" and ">>" for both accessibility and SEO, and "Download the CSE326 syllabus (PDF)" beats "here".

Link or button? If activating it takes the user somewhere (a page, a section, an email), use <a href>. If it performs an action (submit, save, open a menu), use <button>. An <a href="#"> pretending to be a button, or a div pretending to be a link, breaks keyboard and screen-reader behaviour.

8.4 The image element

<img> embeds an image. It is a void element (no closing tag) and it takes two attributes you should treat as mandatory: src, the resource location (a relative path such as images/campus.jpg or an absolute URL), and alt, a meaningful text alternative.

<img src="https://picsum.photos/id/1015/300/160" alt="A river winding between forested mountains">
<p>Break the src on purpose to see the alt text appear:</p>
<img src="missing-file.jpg" alt="Main campus building at sunset">

alt does three jobs at once: a screen reader reads it aloud to a blind user; the browser displays it if the image fails to load; and search engines use it to index the image. An image written with no alt at all leaves a screen-reader user with nothing useful, often just the file name read out.

Writing alt text

Kind of imageAlt textExample

Good alt text describes purpose, not "image" or "photo": alt="Students entering the library" beats alt="photo".

width, height and loading

Give every image its width and height in pixels. The browser then reserves the space while the file downloads, so the page does not jump about as images arrive (the effect is called cumulative layout shift). It does not make the file smaller or sharper; it prevents the jump. For images far down a long page, add loading="lazy": the browser defers fetching them until the user scrolls near, a real performance win. (There is no defer, async or preload="none" on images.)

<img src="campus.jpg" alt="Main campus building" width="500" height="300" loading="lazy">

Making an image a link

Put the <img> inside an <a>: <a href="index.html"><img src="logo.svg" alt="LPU home"></a>. There is no href on an image and no <imglink> element. The alt text becomes the link text, so it should say where the link goes.

8.5 figure and figcaption

When an image (or a diagram, chart or code listing) is a self-contained unit with a caption, wrap it in <figure> and put the caption in <figcaption>. The caption is part of the figure, and assistive technology associates the two. This is exactly the markup this book uses for its own diagrams.

<figure>
  <img src="https://picsum.photos/id/1011/320/180" alt="A person kayaking on a calm lake" width="320" height="180">
  <figcaption>Figure 1: Morning practice on the lake.</figcaption>
</figure>

Do not mix this up with <caption>, which is the title of a table (Chapter 19), or with <picture>, which is about choosing between image files, not captioning.

8.6 Responsive images: srcset, sizes and picture

A phone on mobile data should not download the 2000-pixel image that a desktop needs. HTML5 gives two tools.

srcset and sizes: let the browser pick a file

srcset lists several image files with their widths, so the browser can choose the one suited to the display: srcset="small.jpg 480w, large.jpg 1200w". The sizes attribute tells the browser how wide the image will be displayed (for example "100vw" on small screens, "600px" otherwise), which is what it needs to pick a file from srcset. Note the division of labour: srcset lists candidates, sizes states the displayed width; neither gives file sizes or an aspect ratio.

<img src="campus-800.jpg"
     srcset="campus-480.jpg 480w, campus-800.jpg 800w, campus-1200.jpg 1200w"
     sizes="(max-width: 600px) 100vw, 600px"
     alt="Main campus">

picture: different images for different conditions

<picture> offers several image sources for different conditions, each in a <source> with a media query or a type, with an <img> inside as the required fallback. The browser takes the first source whose condition matches; if none does, or the browser is old, it uses the <img>. It can hold many sources, it does not replace <img>, and it is not for captions.

<picture>
  <source media="(max-width: 600px)" srcset="mobile.jpg">
  <img src="desktop.jpg" alt="Campus">
</picture>

Exam-style checks

Which attribute holds a link's destination?L1

Answer: href on <a>. src is for embedded resources such as images; link and url are not attributes.

Which href value jumps to an element with id="contact" on the same page?L2
  • A. href="#contact"
  • B. href="contact"
  • C. href="/contact"
  • D. href=".contact"

Answer: A. The hash marks a fragment; it works only if an element has id="contact", otherwise the click silently does nothing.

In <a href="../about.html">, what does the ../ portion mean?L2
  • A. Start from the site root
  • B. Move up to the parent directory
  • C. Stay in the current directory
  • D. Refer to an external website

Answer: B. A leading / would mean the root; ./ means the current directory.

Which link opens the user's email client addressed to help@example.com, and which lets a mobile user dial a number directly?L1

Answer: <a href="mailto:help@example.com"> and <a href="tel:+919876543210">. The schemes email:, mail:, call:, phone: and dial: do not exist.

Which opens a link in a new tab, and what should be added when the content is untrusted?L3

Answer: target="_blank", paired with rel="noopener noreferrer". Without noopener the opened page can script your tab through window.opener; noreferrer also hides the referring page. rel="stylesheet", download="true" and referrer="none" are wrong.

Which anchor attribute describes the relationship between the current page and the linked document?L2
  • A. type
  • B. href
  • C. target
  • D. rel

Answer: D. rel values include noopener, noreferrer, nofollow and license.

Which anchor attribute prompts the browser to save the linked file instead of opening it?L2
  • A. target
  • B. save
  • C. download
  • D. rel

Answer: C. <a href="file.pdf" download>.

Which link text is better for both SEO and accessibility?L3
  • A. <a href="pricing.html">Click here</a>
  • B. <a href="pricing.html">>></a>
  • C. <a href="pricing.html">More</a>
  • D. <a href="pricing.html">View our pricing plans</a>

Answer: D. Link text should describe the destination; a screen-reader user listing links otherwise hears "click here, more, here".

In <img src="campus.jpg" alt="Main campus building">, src and alt respectively give:L2
  • A. The caption and the file size
  • B. The resource location and a meaningful text alternative
  • C. The width and the height
  • D. The CSS class and the tooltip

Answer: B. src = where; alt = what.

An image is purely decorative and adds no information. Its alt attribute should be written as:L2
  • A. Omitted entirely
  • B. alt="decorative image"
  • C. alt=""
  • D. alt="image"

Answer: C. An empty but present alt tells a screen reader to skip it silently.

A printer icon is used as a print button. Its alt text should describe:L3
  • A. The action the control performs, for example "Print"
  • B. The icon's colours and shape
  • C. The image's file name
  • D. Nothing: alt="" is correct here

Answer: A. Functional images are described by what they do. An empty alt would leave the button unnamed.

A site logo carries the organisation's name. How should it be marked up?L2
  • A. As a <div> containing the word logo
  • B. As a CSS background image with no alt text
  • C. As an <img> with alt=""
  • D. As an <img> with alt text giving the organisation's name

Answer: D. The logo conveys the name, so the name is its text alternative.

An <img> is written with no alt attribute and the file fails to load. What does a screen-reader user receive?L3
  • A. A clear description of the image
  • B. The title attribute is always read out instead
  • C. No useful alternative, often just the file name
  • D. A description generated automatically by the browser

Answer: C. Without alt there is nothing to read; many screen readers fall back to the file name.

Why set width and height on an <img>?L2

Answer: the browser reserves the space so the page does not jump while the image loads. It does not shrink the file or improve quality, and it is not required by HTML.

An image far down a long page should be fetched only when the user scrolls near it. Which markup achieves this?L3

Answer: <img src="a.jpg" alt="..." loading="lazy">. defer, async and preload="none" are not image attributes.

Which pair marks up an illustration with its caption?L1

Answer: <figure> and <figcaption>. caption belongs to tables; picture chooses image files.

Which statement about the <picture> element is correct?L2
  • A. It replaces <img> entirely and needs no fallback
  • B. It offers several image sources for different conditions, with an <img> inside as the fallback
  • C. It can contain only one <source> element
  • D. It is used to group an image with its caption

Answer: B. The img inside is mandatory; it displays the chosen file and serves old browsers.

What is the purpose of the srcset attribute, and what does sizes tell the browser?L3

Answer: srcset lists several image files (with widths) so the browser can choose one suited to the display; sizes says how wide the image will be displayed, so the browser can pick a file from srcset. Neither gives file sizes, forces load order or sets an aspect ratio.

Your site works locally but every link breaks on GitHub Pages. What is the most likely cause?L3

Answer: wrong relative paths, or capitalisation: the web server is case-sensitive, so About.html and about.html are different files there, even though Windows treats them as the same.

How do you make an image clickable?L1

Answer: put the <img> inside an <a>: <a href="..."><img src="..." alt="..."></a>. Images have no href.

Quick revision

Key takeaways

  1. <a href> makes a link; href is the destination. <link> is not a hyperlink.
  2. Absolute URLs have protocol and domain; relative URLs resolve from the current page: same folder, sub/folder, ../ parent, /root. Servers are case-sensitive.
  3. #id jumps within a page (needs a matching id); mailto: opens email; tel: dials.
  4. target="_blank" opens a new tab; add rel="noopener noreferrer" for untrusted sites; download saves the file; rel = relationship.
  5. Link text describes the destination, never "click here".
  6. <img> is void: src (location) and alt (text alternative). Informative: describe; decorative: alt=""; functional: the action; logo: the name. width/height stop layout jumps; loading="lazy" defers off-screen images.
  7. figure + figcaption for a captioned illustration; picture + source + img fallback for conditional sources; srcset lists candidates and sizes states the displayed width.
