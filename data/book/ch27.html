Text Styling

Chapter 26 chose the letters. This chapter arranges them: where the text sits in its box, whether it is underlined, whether it shouts in capitals, whether it casts a shadow, and what happens when a very long word meets a very narrow column.

27.1 text-align: where the text sits

text-align controls the horizontal alignment of text inside its element. Four values matter:

ValueEffectUse for
leftLines start at the left, ragged right edgeBody text. The default, and almost always right.
rightLines end at the rightNumbers in a table column, dates
centerEach line centredShort headings, captions, buttons
justifyWord spacing stretched so both edges line upPrint. Use with care on the web.
 
<style>
  p { border: 1px dashed #CBD5E1; padding: 8px; margin-bottom: 8px; }
  .l { text-align: left; } .r { text-align: right; }
  .c { text-align: center; } .j { text-align: justify; }
</style>
<p class="l">Left aligned. This is the default and the easiest to read, because every line starts in the same place.</p>
<p class="r">Right aligned.</p>
<p class="c">Centred.</p>
<p class="j">Justified text stretches the spaces between words so that both edges are straight, which can leave ugly rivers of white running down a narrow column.</p>
Two alignment mistakes. First, do not centre paragraphs. The eye needs a fixed left edge to return to; centred body text is measurably slower to read. Centre headings, not prose. Second, justify carefully: a browser cannot hyphenate as neatly as a typesetter, so narrow justified columns develop distracting white gaps, and readers with dyslexia find them especially hard.

One more thing text-align does not do: it does not centre a box. text-align: center centres the content inside an element. To centre the element itself you need margin: 0 auto (Chapter 28) or Flexbox (Chapter 30). Confusing the two is a very common early mistake.

27.2 text-decoration: lines on text

text-decoration adds or removes decorative lines: underline, overline, line-through, or none.

Its most frequent job in real code is removing the underline browsers put on links:

<style>
  a { color: #1D4ED8; }
  .plain  { text-decoration: none; }
  .fancy  { text-decoration: underline wavy #E07B1E; }
  .thick  { text-decoration: underline 3px; text-underline-offset: 4px; }
  .gone   { text-decoration: line-through; color: #94A3B8; }
</style>
<p><a href="#">Default underlined link</a></p>
<p><a href="#" class="plain">No underline</a></p>
<p><a href="#" class="fancy">Wavy orange underline</a></p>
<p><a href="#" class="thick">Thick underline, pushed down</a></p>
<p class="gone">Old price: 1500</p>

The full shorthand takes a line, a style and a colour: text-decoration: underline wavy #E07B1E;. The available styles are solid, double, dotted, dashed and wavy.

If you remove a link's underline, give it something else. Colour alone is not enough: a colour-blind reader may not see any difference between your link and the text around it. Keep a weight change, a bottom border, or bring the underline back on hover. This is a WCAG requirement, not a style opinion (Chapter 20).

For text that has genuinely been deleted, use the <del> element rather than line-through (Chapter 6). The element carries meaning; the CSS only draws a line.

27.3 text-transform: changing case for display only

text-transform changes the letter case of text without changing the HTML:

  • uppercase — EVERY LETTER CAPITAL
  • lowercase — every letter small
  • capitalize — The First Letter Of Every Word
  • none — leave it alone (the default)

This is worth understanding properly. The words in your HTML file are untouched. Only the display changes. So the text a screen reader receives, the text a search engine indexes and the text a user copies are all still the original — which is exactly what you want.

<style>
  .u { text-transform: uppercase; }
  .l { text-transform: lowercase; }
  .c { text-transform: capitalize; }
</style>
<p class="u">asha kumar, b.tech cse</p>
<p class="l">ASHA KUMAR, B.TECH CSE</p>
<p class="c">asha kumar, b.tech cse</p>
<p>Copy any line above and paste it somewhere: you get the original text back.</p>
Why this matters. If you type a heading in capitals in the HTML, a screen reader may spell it out letter by letter, and the capitals are locked in forever. Type it normally and use text-transform: uppercase in the CSS: it looks identical, reads correctly, and one line of CSS can undo it later.

Note that capitalize is crude — it capitalises every word, so "the internet of things" becomes "The Internet Of Things". For real title case, type the words the way you want them.

27.4 text-shadow

text-shadow paints a copy of the text behind itself, offset and blurred. It takes up to four values, in this order:

text-shadow: 3px 3px 5px #999;
/*           |   |   |   |
             |   |   |   the shadow's colour
             |   |   how blurred (0 = sharp edge)
             |   how far DOWN
             how far RIGHT                                */

Negative numbers move it left and up. Leave out the blur and you get a hard offset copy, which suits retro headings.

<style>
  p { font-size: 28px; font-weight: 800; margin: 10px 0; color: #0B2545; }
  .soft { text-shadow: 3px 3px 5px #999; }
  .hard { text-shadow: 2px 2px 0 #E07B1E; }
  .glow { color: #fff; background: #0B2545; padding: 6px 12px;
          text-shadow: 0 0 12px #FF9933; }
  .lift { text-shadow: 0 1px 0 #fff, 0 2px 3px rgba(0,0,0,.35); }
</style>
<p class="soft">Soft shadow</p>
<p class="hard">Hard offset</p>
<p class="glow">Glow</p>
<p class="lift">Two shadows, comma separated</p>

Its one genuinely practical use is making text readable over a photograph, where a soft dark shadow lifts light text off a busy background.

Restraint. A shadow lowers contrast at the letter edges. On body text it makes reading harder, so keep it for large headings and text over images.

27.5 Indents, spacing and the long-word problem

text-indent

Indents the first line only of a block, the way a printed novel does: text-indent: 2em;. On the web, space between paragraphs usually does the job better.

white-space

Remember from Chapter 3 that HTML collapses runs of spaces and newlines into one space. white-space changes that behaviour:

ValueEffect
normalCollapse spaces, wrap lines as needed. The default.
nowrapNever wrap — keep it on one line, whatever the width. Useful for a button label or a table cell that must not break.
preKeep every space and line break, like the <pre> element.
pre-wrapKeep spaces and breaks, but still wrap when the line is too long. The most useful of the three.

When a long word breaks the layout

A very long unbroken string — a URL, an email address, a German compound noun — cannot be wrapped at a space, because there is no space. By default it simply sticks out of its box and can push a whole layout sideways on a phone.

<style>
  div { width: 210px; border: 2px solid #CBD5E1; padding: 8px;
        margin-bottom: 10px; }
  .fix { overflow-wrap: break-word; }
  .cut { white-space: nowrap; overflow: hidden; text-overflow: ellipsis; }
</style>
<div>https://example.com/a/very/long/path/that/never/ends/at/all</div>
<div class="fix">https://example.com/a/very/long/path/that/never/ends/at/all</div>
<div class="cut">https://example.com/a/very/long/path/that/never/ends/at/all</div>

Two cures, and they suit different situations:

  • overflow-wrap: break-word lets the browser break inside the word as a last resort. Use it where the whole text must be visible.
  • text-overflow: ellipsis (with white-space: nowrap and overflow: hidden) cuts the text off and adds a small ellipsis. Use it in a tight card or a table, where a tidy line matters more than the full text.

Exam-style checks

  
Which property controls the horizontal alignment of text inside an element?L1

    
  • A. align
  • B. text-align
  • C. align-text
  • D. horizontal-align

    
Answer: B. Its common values are left, center, right and justify.

  
Which property adds or removes decorative lines such as an underline?L1

    
text-decoration, with values none, underline, overline and line-through. text-decoration: none is how a link's underline is removed.

  
Which property changes the letter case of text without changing the HTML?L2

    
text-transform, with uppercase, lowercase and capitalize. The underlying text is untouched, so copying it gives back the original.

  
Why type a heading normally and capitalise it with CSS, rather than typing capitals in the HTML?L3

    
Because the HTML keeps the real text. Screen readers may spell out a word typed in capitals letter by letter, search engines index the original, users copy the original, and one line of CSS can change the presentation later.

  
In text-shadow: 3px 3px 5px #999;, what does each value mean?L2

    
Horizontal offset, vertical offset, blur radius, colour — in that order. Setting the blur to 0 gives a hard-edged offset copy; negative offsets move the shadow left and up.

  
Why is centring long paragraphs a bad idea?L3

    
Because every line starts in a different place, so the eye has to hunt for the beginning of each one. Centre short headings and captions; keep body text left-aligned.

  
A long URL sticks out of its card and breaks the layout on a phone. Which declaration fixes it?L3

    
overflow-wrap: break-word; lets the browser break inside the word when there is nowhere else to break. If you would rather cut it off tidily, use white-space: nowrap; overflow: hidden; text-overflow: ellipsis; instead.

  
What is the difference between text-align: center and margin: 0 auto?L3

    
text-align: center centres the content inside an element; margin: 0 auto centres the element itself within its parent (and needs a width to work). Mixing them up is one of the most common early layout mistakes.

  
Which value of white-space stops text wrapping onto a second line?L2

    
nowrap. It is normally paired with overflow: hidden and text-overflow: ellipsis so the text is cut off neatly rather than spilling out.

  
You remove the underline from every link. What must you add, and why?L3

    
Another visual cue that does not depend on colour — a bold weight, a bottom border, or an underline restored on hover and focus. Colour alone is invisible to colour-blind readers, and WCAG requires links to be distinguishable by more than colour.
