1  GitHub access

This site lives in the GitHub repository ProfTarun/CSE326. Publishing writes the pack into it, so this page needs a GitHub access token that may change that repository's files. It stays in this browser only.

How to make the token (once)
  1. Signed in to GitHub, open Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Name it CSE326 learning reports; pick an expiry (e.g. 1 year).
  3. Repository access: Only select repositories → CSE326.
  4. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  5. Generate, copy the token, paste it above, tick Remember and press Check access.

2  Publish a pack

In the OMR Scan app: project → Class analysis and student reports → For the CSE326 website. It shares a ZIP (put that here) and a list of student codes (keep that, and give each student their code).
